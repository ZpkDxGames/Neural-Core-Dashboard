# Phase 3.1 regression specification and evidence

The original 310-test matrix is retained. The six original browser spec files (141 cases), private browser file (five cases), original authentication, Brain, backend and V2 files are unchanged. Private integration tests append cases after the original 14; the shared fixture adds explicit 005 migration rollback/application. No original assertion is deleted, weakened or skipped.

New contract cases cover confirmation field types and cardinality, duplicate/unsafe JWT members, invalid UTF-8/base64url, exact authentication bindings, genuine key misconfiguration, and authenticated encryption/tampering/key loss. New SQL/TLS cases cover initial intent commit failure, sink success followed by activation SQL/commit failure, lost intent/activation/sink acknowledgment, deterministic restart, timeout/late write fencing, duplicate concurrent completion, rotation rollback/retry, revocation while sink unavailable, expiry/consent cleanup, primary-family revocation, bounded attempts, issuer/SQL permissions and restricted rotation lifetime.

Local implementation checks use Node 24.19.0 and serialized PostgreSQL WASM; they do not certify native connection isolation or independent native roles. Fresh root/backend locked installs succeeded. Before the changes, private contracts passed 21/21 and original private integrations passed 14/14. The original local auth/unit suite reported 52 passed and one live-Redis case unavailable; the required CI suite runs that case against real Redis. No local skip is represented as complete-suite certification.

The required CI pipeline uses Node 22, native PostgreSQL 16, separate restricted API/issuer logins, Redis 7.4 and Playwright Chromium. It runs all original suites plus additions, strict TypeScript, optimized production build, parity/token lint, migration checksums/rollback/concurrency, synthetic SQL backup/restore, scale benchmark, locked root/backend advisory audits, browser credential exclusion and compiled default-off smoke tests. `.github/workflows/verify.yml` retains raw unit/backend/V2/private/Brain logs and browser JSON in the synthetic evidence artifact. Actual final counts, immutable commit/run/artifact identities and full source correspondence are recorded in the delivered `FINAL_CERTIFICATION.md` and evidence package, not inferred from this specification.

Reproduce native tests only with the workflow's explicit disposable loopback `ncore_phase3_test` URLs. Never substitute a live URL. 005 has no CLI, startup hook or environment-derived database URL. Local browser availability and dependency advisory failures are retained as limitations/failure history rather than removed from the record. Dependency versions changed only to resolve the evidenced Next advisory; no security warning was bypassed.
